# GPU Deck infrastructure (`infra/`)

Paths in the table are relative to `infra/`. The step-by-step production guide is [DEPLOYMENT.md](../DEPLOYMENT.md); day-2 operations are in [operations.md](../operations.md).

| Path | What |
| --- | --- |
| `docker/docker-compose.deps.yml` | Local dev dependencies (project `gpu-deck-deps`): Postgres 17 (127.0.0.1:55432) and Redis 7.4 with an ACL user limited to `gpu-deck:*` keys (127.0.0.1:56379), healthchecks, named volumes; `--profile proxy` adds Caddy (`tls internal`) for `https://gpu-deck*.localhost:58443`. Credentials in the gitignored `docker/.env` (generated by `scripts/bootstrap.dev.sh deps up`). |
| `docker/docker-compose.yml` | Control plane on Docker against the dev dependency containers (external network `gpu-deck-deps`; override with `GPUDECK_DATABASE_URL` / `GPUDECK_REDIS_URL`): `admin-api` 8180, `api-layer` 8181, `agent-hub` 8443 (mTLS), `worker`, `beat`, `scheduler`, `web` 3180, `migrate` (profile `tools`). Non-root, read-only root FS, tmpfs, caps dropped. |
| `docker/docker-compose.full.yml` | Overlay adding Postgres 17 + Redis containers; `--profile observability` adds Prometheus, Grafana, OTel collector. |
| `docker/scripts/container-env.sh` | Entrypoint shim: rewrites remaining loopback hosts in the `.env` to `host.docker.internal`. |
| `docker/api/Dockerfile` | Control-plane image (context: repo root; keeps the repo layout under `/srv/gpu-deck` because the backend reads `libs/contracts` at runtime), uid 1000, read-only. Writable: `/app/logs`, `/app/certs`, `/tmp`. |
| `docker/web/Dockerfile` | Next.js standalone image (context: repo root), uid 1001, read-only. |
| `docker/node-agent/Dockerfile` | Agent image for the Kubernetes DaemonSet. |
| `helm/gpu-deck` | Chart: HA replicas, PDBs, HPA (api-layer), topology spread, NetworkPolicies (default deny + the network rules in [security-model.md](../security-model.md)), secret refs, admin + serving ingresses, hub LoadBalancer, migration hook, node-agent DaemonSet, ServiceMonitors, dashboards, PrometheusRule. |
| `observability/` | Prometheus config + alert rules, Grafana provisioning + dashboards (generated), OTel collector config. |
| `offline/` | Air-gapped bundle (`build-bundle.sh`), site installer (`install.sh`), GPU machine installer (`install-agent.sh`). |
| `scripts/cross-compile-agent.sh` | cargo-zigbuild builds of `gpudeck-agent`. |
| `scripts/openapi30.py` | OpenAPI 3.1 → 3.0.3 downgrade for the Terraform provider code generator (`apps/terraform-provider/tools/gen.sh`). |

## Compose

```bash
./infra/scripts/bootstrap.dev.sh deps up      # Postgres + Redis (dev dependencies)
docker compose -f infra/docker/docker-compose.yml --profile tools run --rm migrate
docker compose -f infra/docker/docker-compose.yml up -d --build
# self-contained:
POSTGRES_PASSWORD=... REDIS_PASSWORD=... GRAFANA_ADMIN_PASSWORD=... docker compose \
  -f infra/docker/docker-compose.yml -f infra/docker/docker-compose.full.yml --profile observability up -d
```

Settings: `apps/fastapi/.env` (or `GPUDECK_ENV_FILE`). UI/admin API bind to 127.0.0.1 unless
`GPUDECK_BIND` is set; the hub binds `GPUDECK_HUB_BIND` (default 0.0.0.0, agents dial in).

## Helm

```bash
helm upgrade --install gpu-deck infra/helm/gpu-deck -n gpu-deck --create-namespace \
  --set secrets.existingSecret=gpu-deck-env -f my-values.yaml
```

The Secret holds `SECRET_KEY`, `VAULT_KEYS`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `DATABASE_URL`,
`REDIS_URL`. Set `networkPolicy.*CIDRs`, `ingress.serving.sourceRanges` (your AI gateway's IPs) and the
hosts. GPU nodes in the cluster: `nodeAgent.enabled=true`, `nodeAgent.joinTokenSecret`, label the
nodes `gpudeck.sur950.github.io/gpu-node=true`.

## Dashboards

`python3 infra/observability/grafana/build_dashboards.py` regenerates the three dashboards (GPU
fleet, inference, control plane) from `libs/contracts/metrics.md` names and copies
them (plus the alert rules) into the chart; `--check` fails on stale files or unknown metrics.

## Agent cross-compilation

Targets: `x86_64/aarch64-unknown-linux-gnu.2.28` (glibc ≥ 2.28), `x86_64/aarch64-unknown-linux-musl`
(static), `aarch64-apple-darwin` (built natively on a Mac; Metal/IOKit). Prerequisites (not
installed by the script): `cargo-zigbuild 0.24.1`, `zig 0.17.1`, `rustup target add ...`.

## Offline install

Connected machine: `infra/offline/build-bundle.sh --version X [--with-data-services]
[--with-observability]`. Site: `./install.sh verify`, `load-images --registry ...`, then `compose`
or `helm`, `cli`, `terraform-mirror`; each GPU machine: `sudo ./install-agent.sh --hub ... --token ...`.
Point `HF_ENDPOINT` / `MODELSCOPE_ENDPOINT` at the site mirror.
